# 03 — La marque (étape 4)

**`marque.md`** : le nom, le ton, l'identité. Vérifications selon la méthode RendsMoi — INPI,
domaine, handles — chacune avec la date de la vérification, parce qu'une disponibilité se périme.

Le nom est une décision fondateur. Le dépôt s'appelle `projet-bornes` en attendant ; il se
renommera après.
